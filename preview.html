Before you explore

Two quick things:
Fan-made project
This is an unofficial, fan-made tool. It is not affiliated with, endorsed by, or sponsored by Hello Games.
Procedural data
Star systems are generated procedurally from their portal address, the same way the game does -- they are not scraped from anyone's real save. A system only reflects real in-game data once a traveller has entered it via Edit system, marked "Community edited".
